# Ariadne media (devpost + report)

Every image here comes from a recorded run or from a rendered scene of the demo film. Each label below says which.

- **Regenerate the GIFs:** render each source scene once in GIF mode (`ARIADNE_GIF=1 python/video/render.sh scenes/<scene>.py <Class> -qm --media_dir media_gif`), then run `python/video/tools/make_gifs.py` in `manimcommunity/manim:v0.22.0`. The tool's spec table holds each GIF's time window, speed-up and crop.
- **Regenerate the stills:** `python3 docs/report/figures/src/make_stills.py`, run on the host (needs numpy and Pillow).
